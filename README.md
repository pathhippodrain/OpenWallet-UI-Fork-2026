## 🧭 Introduction

OpenWallet UI Fork 2026 is a customized build of an open-source crypto wallet, focused on interface improvements and developer ergonomics.
It keeps the original signing logic untouched — only the UI layer and build pipeline are modified.
Based on Trust Wallet Core and open standards.

## 🎛️ What's Included

- 🎨 Redesigned interface
- 🔐 Original signing logic (untouched)
- 💰 Bitcoin, Ethereum, EVM chains
- 🧩 Modular UI components
- 🌍 Multi-language support
- 🔧 Configurable RPC endpoints
- 📴 Offline mode for cold storage
- 🔄 Manual update checks

## 🖥️ System Requirements

- Windows
- 4 GB RAM or more
